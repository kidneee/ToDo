# ToDoリストアプリ（シンプル版）

## 概要

このアプリは、タスクを管理するシンプルなToDoリストアプリです。ユーザーはタスクを追加、削除、完了状態を切り替えることができます。JavaScriptを使って、DOM操作やイベント処理の基礎を学ぶことを目的としています。

## 要件

### 1. タスクの追加
- テキスト入力フォームと「追加」ボタンを用意
- 入力された内容をリスト（`ul/li`）に追加

### 2. タスクの削除
- 各タスクに「削除」ボタンをつけて、クリックしたらそのタスクをリストから消す

### 3. タスクの完了状態切り替え
- 各タスクに「完了」ボタンまたはチェックボックスをつけて、クリックするとタスクの見た目が変わる（例：取り消し線）

## 必須ポイント

- JavaScriptでDOMを動的に操作する（要素の追加・削除・更新）
- イベントリスナーを動的に作成された要素にも対応させる
- HTML/CSSはなるべくシンプルでOK

## 発展課題

### 1. ローカルストレージへの保存
タスクをローカルストレージに保存し、ページを再読み込みしても残るようにする。

### 2. タスクのフィルター機能
タスクを「すべて」「未完了」「完了」の3つのフィルターで表示切替する機能を追加する。
